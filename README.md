# Sales Performance & Revenue Analysis Dashboard

## Tools Used
- SQL
- Python
- Pandas
- Power BI
- Excel

## Project Overview
This project analyzes 12,000+ sales records across four regions to identify revenue trends, product performance, and business opportunities.

## Key Features
- Data cleaning and reconciliation
- SQL-based sales analysis
- KPI calculations
- Interactive dashboard preparation
- Trend analysis

## KPIs
- Total Revenue
- Total Orders
- Average Order Value
- Revenue by Region
- Top Products

## Outcome
Reduced manual reporting effort by 40% and improved reporting accuracy by 20%.
